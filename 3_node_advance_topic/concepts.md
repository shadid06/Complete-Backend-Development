# Node.js Advance Topics

Welcome to the **Node.js Advance Topics** module!

## Topics Overview

1. **Main js thread**
   - normal app JS executes on one main JS thread
2. **V8 engine**
   - parsing js
   - executes js
   - manage call stack
   - heap memory and performing garbage collection

3. **Node js core apis**
   - http
   - path
   - streams
   - buffer
   - process
   - os
   - times etc
   - core apis -> some of this written in js

4. **c++ bindings**
   - connect js facing apis to native functionalities
   - js code communicate with
   - libuv
   - os api
   - native lib

5. **libuv**
   - Event loop
   - file system events
   - timers
   - child processes
   - dns
   - native library used by node
   - async i/o handling

6. **os module**
   - file system
   - tracking time
